# Fly-in

## Description

この課題は、与えられた制約下ですべてのドローンをスタートからゴールまでなるべく少ない手数で移動させるというシミュレーションをするプログラムを作成する問題である。
これらの課題は、マルチエージェント・パスファインディング問題(MAPF) という問題に一般化できる。

課題で Python 3.10以降でコードを記述するよう指定しており、既存のグラフ系のライブラリを利用することは禁じられている。

これらの課題を通して、以下のことを学習した。

- A-maze-ingから引き続き学習していた、グラフ理論について
- ダイクストラ法、アルゴリズムについて
- オブジェクト指向プログラミング / Pythonでのプログラムの設計について
- Pydanticを用いたデータのバリデーションについて
- Ruffなどの静的解析ツールを用いたコードの品質向上について
- ...

### 与えられている制約

#### Hub - ハブ

- スタートのHubとゴールのHubが1つずつ与えられる
- それ以外のHubが0個以上与えられる
- Hubの座標は整数で与えられる
- Hubには最大1台、設定で指定された場合には複数台のドローンが同時に存在することができる
- `priority` や `restricted` という属性を持つHubが存在する

#### Drone - ドローン

- Droneの数は1以上の整数で与えられる
- DroneはHubとHubの間を原則1ターン、restrictedという属性を持つHubに移動する際には2ターンをかけて移動する
- ...

#### Connection - ハブ間の接続

- Connectionは、HubとHubの間の接続を表す
- この接続は、双方向である
- この接続には上限が存在する

## Algorithm

このセクションでは、アルゴリズムについて解説する。

### 概要

このプログラムでは、それぞれのドローンに対してPrioritized Planningと呼ばれる方法を用いて、現時点で利用可能な最短経路を求めることを繰り返し、順番を決定し次第それを記録して次のドローンについて経路を求める。それぞれの最短経路についてはダイクストラ法を用いて算出した。

このような手法を用いることで、貪欲に順番にすべてのドローンそれぞれに対して経路を求めることで、最適のターン数で終了するとは限らないが、ドローンがスタートからゴールまで到達するルートが最低でも1つある限り、必ず実行に成功する解を導き出した。また、課題に付属のmapについては全て課題で求められている最適のターン数による回答を導き出すことができた。

### 時間計算量

V をハブの数、E を接続の数、D をドローンの数、T をターン数の上限（`2(V − 1) + D − 1`）とする。

1台ごとに「(ターン, ハブ)」を状態とするダイクストラ法を行い、それをドローンの台数分繰り返す。

計算量は以下の掛け算で求められる。

- **D**: ドローンの台数分、探索を繰り返す
- **T · (V + E)**: 1回の探索で試す移動の数。状態は最大 T·V 個あり、それぞれから「待機」と「隣接ハブへの移動」を試す
- **E + log(T·V)**: 移動1回ごとの処理。Connectionの容量確認に O(E)、heapq への次の探索予定のハブの追加に O(log(T·V)) かかる

このため計算量は
`O(D · T · (V + E) · (E + log(T·V)))` となる

### ダイクストラ法とは?

- 最短経路を算出するためのアルゴリズム
- それぞれのnodeに対して最短の距離を算出して保存する
- ゴールまでの経路を見つけた後、最短距離となる経路をスタートへとたどっていくことで最短経路を算出する

#### 具体的には?

スタート地点のノードとそこに到達するためのコスト(0) を優先度付きキューに追加したあと、以下のことを繰り返す。

1. キューの中から最小のコストとなるノードを取得し、キューからは削除する。
1. それを「訪れた」とマークする。
1. 現在のノードとエッジにより接続されている、まだ訪れていないノードに対して以下のことをする。
   - それぞれ、そこまで現在のノードから到達した場合のコストを算出する。
   - もし、そのコストが現時点とのその最小コストより低い場合、またはまだコストが未設定である場合には、現在のコストで置き換える。

その上で、ゴールのハブに到達した場合には、そこまでの最短経路を算出することができる。

### 今回の課題では?

以下のような処理の流れで、それぞれのドローンに対して最短経路を算出した。

- まず、スタート地点とそのコストを優先度付きキューに追加

その上で、以下のことを繰り返す。

1. キューから最小のコストとなり、かつ同じコストである場合には`priority`という属性の有無を考慮して優先度が高い移動パターンを1つ取り出す
1. 取り出したものと隣接するHubへ移動した場合、またはその場にとどまることの選択肢を取る行動パターンについて、それぞれ以下の操作をする
   - 他のドローンの行動予定とそれが重複しないかどうか検証する
   - もし、行動が重複しない場合にはその移動パターンをキューに追加する

#### heapqの使い方について

今回は、これらのデータの取り出しや追加の操作を効率的に行うために、Pythonの標準ライブラリであるheapqを利用した。

heapqは、リストへの要素の取り出しや操作を効率的に行うことができるライブラリである。heapqを利用することで、リストの中から値が最小の要素を取り出す操作や、要素の追加を効率的に行うことができる。なお、heapq は既存の`list`型を用いる。

どの値が最小であるかについては、heapqにおいては内部で`<`演算子を利用した比較が行われる。

なお、ヒープとはデータ構造の1つであり、木構造のうち親のノードの値が子ノードの値よりも小さい(あるいは大きい)という性質を持つ。ヒープソートなどのアルゴリズムに利用されており、今回の優先度付きキューの実装の効率化のために利用した。

##### 利用方法

1. 空のリストを用いるか、要素が空でない場合のみ、 `heapq.heapify()` 関数を利用して、リストをヒープとして初期化する。
1. `heapq.heappush()` 関数を利用して、要素をヒープに追加する。
1. `heapq.heappop()` 関数を利用して、ヒープから最小の要素を取り出す。
