# Fly-in

## Description

このプロジェクトは、与えられた制約下でPythonを用いてすべてのドローンをスタートからゴールまでなるべく少ない手数で移動させるというシミュレーションをするプログラムを作成する問題です。

これらの課題は、マルチエージェント・パスファインディング問題(MAPF) ということに一般化できます。

これらの課題を通して、以下のことを学習しました。

- グラフ理論
- アルゴリズムについて
- ...
